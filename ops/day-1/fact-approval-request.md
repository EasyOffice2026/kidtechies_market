## Why this document exists

The six marketing agents are built so they cannot invent a product fact. Every
number they use comes from one file, `product-facts.md`, and anything not in
that file simply does not get written.

That design only works if the file is right. So this is the one document that
needs your signature before anything goes to a parent.

**A note on where the numbers came from.** The development specification says to
verify product numbers against your live website. We are not doing that, and you
should know why: the Growth Dossier identifies the site's own headline value
claim — *"23:48 of animated film"* beside the $70 price — as an error to retire.
Verifying against the site would copy that error into the file every agent
treats as truth. So the numbers below come from the Growth Dossier and from you,
and where the site disagrees, **the site gets corrected**. Each of those
corrections is listed in Part 4.

Please tick **Confirm** or write the correct value. An unconfirmed number is not
a small gap — it means the agents cannot write about that part of the product at
all.
